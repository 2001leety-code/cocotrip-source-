# Blogger 이미지 복구 기록 — 2026-07-26

## 증상

- `cocotripkr.blogspot.com`의 게시글 사진과 목록 썸네일이 브라우저 환경에 따라 깨진 이미지로 표시됨.
- 게시된 13개 글의 본문 이미지 24개가 모두 외부 원본 주소를 직접 참조하고 있었음.

## 근본 원인

- 본문 이미지가 CocoTrip이 관리하는 저장소가 아니라 Wikimedia Commons, 한국관광공사, Unsplash 주소에 의존함.
- 이 가운데 6개는 `http://tong.visitkorea.or.kr` 주소여서 HTTPS 블로그에서 Google 이미지 프록시 변환에 추가로 의존함.
- 외부 서버의 속도 제한, 핫링크 차단, 프록시 캐시 또는 사용자 브라우저의 추적 방지 설정이 개입하면 원본이 살아 있어도 블로그에서는 액박이 날 수 있는 구조였음.

## 수정

- 외부 원본 24개를 WebP로 변환해 `public/blog-images/2026/`에 자체 호스팅.
- 최대 가로·세로 1,600px, WebP 품질 82로 최적화.
- Blogger 게시글 본문의 이미지 주소를 `https://cocotripkr.com/blog-images/2026/...`로 교체.
- 기존 대체 텍스트와 사진 출처 표기는 유지.

## 검증 기준

1. 저장된 WebP 24개가 모두 디코딩되고 가로·세로가 0보다 커야 함.
2. Vercel 운영 배포 뒤 24개 URL이 모두 HTTP 200과 `image/webp`를 반환해야 함.
3. Blogger 공개 피드의 이미지 24개가 모두 `https://cocotripkr.com/blog-images/2026/` 아래 주소여야 함.
4. 게시글 13개를 실제 브라우저로 열었을 때 각 본문 이미지의 `naturalWidth`가 0보다 커야 함.
5. 블로그 목록 썸네일이 Google 프록시를 거치더라도 원본이 CocoTrip HTTPS 주소에서 제공되어야 함.

## 오답노트

- 외부 사진 URL이 현재 200이라고 해서 운영에 안전한 것은 아니다. 게시물용 사진은 발행 전에 CocoTrip이 관리하는 HTTPS 저장소로 복사한다.
- `http://` 이미지 주소는 게시 금지한다.
- 게시 후에는 원본 URL 확인으로 끝내지 말고, Blogger 공개 페이지에서 실제 렌더링 크기까지 확인한다.
