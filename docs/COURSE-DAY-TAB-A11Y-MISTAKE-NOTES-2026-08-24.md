# Course Builder Day 탭 접근성 오답노트 (2026-08-24)

## 무엇이 잘못됐나

`Day 1` 바로 뒤에 장소 수 `0`을 구분자 없이 넣어 화면에는 `Day 1 0`, 화면읽기에는 `Day 10`으로 전달됐다. 숫자 배지는 시각적으로 작아도 버튼 이름 계산에는 그대로 붙는다.

## 재발 방지

- 숫자 배지는 괄호 등으로 본문과 시각적으로 구분한다.
- 버튼에는 완성된 `aria-label`을 따로 주고, 중복되는 시각 배지는 `aria-hidden="true"`로 숨긴다.
- 빈 상태와 값이 있는 상태 모두에서 번호와 개수가 붙지 않는지 역할 기반 테스트로 잠근다.
