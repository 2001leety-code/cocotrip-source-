# GSC sitemap lastmod 오답노트 — 2026-10-05

- 증상: 2026-09-27 지역 콘텐츠 수정 뒤에도 `/region/paju`, `/region/ganghwa`, `/region/incheon`의 sitemap `lastmod`가 `2026-08-29`로 남아 있었다.
- 근본원인: 정적 sitemap과 일치 테스트가 기존 날짜를 고정해 두어 이후의 실제 콘텐츠 변경일을 반영하지 못했다.
- 수정 범위: 세 URL의 날짜를 `2026-09-27`로 바로잡고, 테스트가 이 세 URL과 나머지 15개 URL의 날짜를 각각 확인하도록 했다.
- 재발 방지: 실제로 의미 있는 콘텐츠 변경이 확인된 URL에만 해당 날짜를 반영한다. 빌드 날짜로 sitemap 전체를 일괄 갱신하지 않는다.
- 한계: `lastmod` 수정은 검색엔진의 색인이나 재방문을 보장하지 않는다.
- 별도 CI 함정: `owner-controller-preflight`의 fixture `checkedAt: 2026-09-01`은 실행일 기준 30일 뒤 만료될 수 있어 테스트에 기준일을 명시했다. fail-closed 검증 로직과 운영 설정은 변경하지 않았다.

## 같은 날 후속 콘텐츠 개선

- 확인된 결함만 수정했다. K-beauty 글의 실제 사진은 춘천 닭갈비 골목이어서 본문 두 사진과 목록 사진을 제거했다. 새로운 사진·출처·장소 사실은 만들지 않았다. 경주와 템플스테이 본문에는 여행 맥락에 맞는 지역·투어·관련 글 연결을 보강했다. 이미 있던 공항↔SIM, 환율↔뷰티 연결은 그대로 두었다.
- 지역 7개의 검색 제목·소개를 여행 선택 목적에 맞게 구체화하되 메뉴·지역 목록의 짧은 이름은 유지했다. 인천 시내와 실제 강화도 상품을 구분했고 전주의 중복 차량 안내를 없앴다. 같은 형식이나 짧은 본문이라는 이유만으로 미색인 원인을 확정하지 않는다.
- 서울 투어의 9시간 계약은 유지한다. 도착 간격이 앞 체류·이동 시간보다 짧거나 마지막 체류까지가 상품 시간을 넘으면 방문 순서만 보여주고 상세 시각은 예약 전 확인을 안내한다. 목록과 지도 팝업에도 모순된 시각을 남기지 않는다. 강화도·경주의 범위 표시는 전체 이용시간이 아니라 첫·마지막 정류장 도착이라는 뜻이다. 실제 픽업·복귀 시각은 자료가 없어 추가하지 않았다.
- 실제 고친 지역 7개·투어 3개·가이드 3개·가이드 목록에만 `2026-10-05`를 반영했다. 다른 URL 날짜와 발행일은 유지한다. 수정한 가이드의 본문·목록 `updated`도 서로 일치한다.
- 회귀 테스트는 수정 전 잘못된 사진·링크 누락·지역명뿐인 제목·중복 안내·시간 모순·낡은 날짜에서 실패하는 것을 확인하고 추가했다. 전체 검사에서 예전 제목 문자열을 고정한 테스트가 실패해 새 제목 우선순위와 지역명/없는 지역의 fallback을 검증하도록 정정했다. 실제 화면 제목·설명은 별도 렌더 테스트로도 확인한다.
- 로컬 화면은 운영 자격증명을 사용하지 않고 테스트용 Firebase 설정과 기존 localhost 전용 투어 fixture로 열었다. Chrome 자동 번역이 원문 한국어도 재번역하는 현상은 사이트 번역과 구분한다. 네 언어 원문은 렌더 테스트로 검사하고, 브라우저에서는 모바일 폭·방문 순서·시각 숨김·링크 동작을 확인한다.
- 이 수정은 Google 색인을 보장하지 않는다. 기존 접수 URL은 중복 요청하지 않고, 실제 배포 후 재크롤 시각과 그 이후 색인 판정을 따로 확인한다. Vercel의 실제 Googlebot 차단 여부는 정상 계정 연결 뒤 요청 기록 확인이 남아 있다.
