# CocoTrip 금액 계약 및 검증 기록 (2026-09-24)

🌐웹(cocotripkr.com). 금액 변경·검증 상태를 먼저 적는다. 이 문서는 로컬 합성 경계에서 확인한 코드 계약이며 실제 결제·운영 저장·예약 성공을 뜻하지 않는다.

## 확인된 금액 위험과 조치

- **서울 야간 투어 표시가와 주문가가 달랐던 결함:** 이전 실행 기록에는 2인 주문에서 화면 ₩140,140, 주문 스냅샷 ₩330,000, PayPal 요청 $236.00이 남아 있다([이전 QA 기록](QUALITY-FOLLOWUP-2026-09-23.md)). SKU가 새 `tour_seoul_night` 계약으로 연결되지 않고 차터 그룹 가격으로 처리되던 문제다. 현재 계약은 **1인 $49**이며 서버·화면·장바구니가 같은 SKU와 인원수를 사용한다. 기본 2인 합계는 $98.00이다. 야간 투어 자체에는 차터 야간할증을 중복 적용하지 않는다.
- **서울 프라이빗 기본가:** 가격 정본은 ₩337,500 = **$250.00 기본가**다. 차터 KRW→USD 환산은 고정 ₩1,350/USD와 정수 달러 반올림을 사용한다. 추가 옵션·야간 할증은 별도 계약대로 더해질 수 있다.
- **쿠폰 표시와 청구 불일치:** 실제 `applyPromoCode`와 `createPaypalOrder` handler에 같은 1인 야간 투어 WELCOME5 입력을 넣어, 표시 할인율과 생성 주문 스냅샷 원화 금액이 5% 할인으로 일치함을 확인했다. 5% 할인이 켜지는 조건으로 검사했고, 운영 기능 플래그를 바꾸지 않았다. 차터/`both` 쿠폰 범위에는 `tour_seoul_night`만 추가했으며 다른 투어 SKU는 허용하지 않는다.
- **캡처 출처 검증:** 주문 snapshot이 없거나 USD/통화가 유효하지 않으면 PayPal capture 전 409, snapshot 읽기 실패는 503으로 닫힌다. 저장한 상품·예약일·USD/KRW·환율이 예약 기록에 이어진다. `PAYMENT_STRICT_PROVENANCE` 설정과 관계없이 동작한다. 프로세서가 저장 원장 조회에서 예외를 만나면 503 `ORDER_CHECK_UNAVAILABLE`을 반환하며 요청 본문 금액으로 Sheets/이메일 처리를 계속하지 않는다.
- **MOOD 원화 충전:** 양의 안전 정수만 받고, 저장 잔액이 손상됐거나 합계가 안전 정수 범위를 넘으면 트랜잭션 write 없이 거절한다. 별도 충전 상한은 만들지 않았다. 실제 충전은 운영자 권한이 확인된 요청 전용이며 일반 손님의 임의 충전 권한을 뜻하지 않는다.
- **AI 플래너:** 기존 전체 생성 기본가 **$9.90**과 쿠폰 금지 정책을 유지한다. `applyPromoCode` 미리보기에도 기존 공통 정책을 적용한다. 원화 환산 판매가의 반올림과 별개로, 기존 달러 정찰가 $9.90을 $10으로 바꿀지도 질문했으며 응답 전에는 이 정찰가를 유지한다.
- **장바구니 합계와 이전 주문:** 상품별로 정수 USD를 확정한 뒤 합산하고 그 금액을 각 예약에 저장한다. 이전 주문은 확정된 부모 USD를 센트 단위로 배분하여 합계를 보존한다. 픽업 시간으로 기존 차량 야간할증을 계산하며, 시간대 가격 조정을 할증보다 먼저 반영한다. 시간대 원본 조회가 불가능하면 PayPal 주문 생성 전에 중단한다.

## 실행 근거

이 작업에서 실제로 실행한 관련 검사는 Node 22.23.2와 기존 격리/offline wrapper를 사용했다. 외부 경계와 데이터는 합성/mock이었고 실제 PayPal·Firestore·메일·Sheets는 호출하지 않았다.

- 쿠폰, top-up, capture snapshot, booking processor 경로: **13개 관련 테스트 파일 145개 통과**.
- 프로세서 저장 원장 초기 조회 오류 503 회귀를 추가한 뒤 프로세서와 슬롯 snapshot 2개 테스트 파일 **46개 통과**. 이 46개는 위 145개와 일부 중복이다.
- `npm run build`, 최종 전체 `npm run lint`, 번들 크기 검사 통과. 린트에서 발견한 테스트 정규식 이스케이프 1건을 수정했다. `git diff --check` 오류 없음.
- 장바구니 실제 주문·캡처 11개 사례 통과: 상품별 합계, 중복 캡처, 1센트 불일치, 신규/기존 주문 보존, 야간할증, 시간대 조정, 조회 불능 차단. 외부 경계는 합성 Firestore/PayPal 응답이다.
- 실제 브라우저 7개 경우 통과: 모바일 영어·PC 한국어 투어 4개, `/charter` 견적 및 PC·모바일 필수 입력 누락 3개. 외부 요청은 차단했고 화면 금액·버튼 차단·가로 잘림·오류를 확인했다.
- 첫 전체 실행은 867개 파일, **11,848 통과 / 18 실패 / 기존 TODO 1**이었다. 18개는 이전 가격·환율·코드 형태 또는 필수 서버 snapshot이 없는 합성 입력과 관련돼 있었다. 검사 의도를 보존해 갱신 후 해당 테스트 파일을 다시 실행했다. 최종 전체 검사 결과는 PR의 정상 pre-push 검사 기록을 따른다.
- 실패 파일 후속 집중 실행: UI 4파일 48개, 가격 5파일 246개·기존 TODO 1, 문의·알림·결제 4파일 242개 통과. 부분 집계는 서로 겹치므로 전체 검사 수에 더하지 않는다.

## 미완료 검증과 경계

- 빌드와 위 브라우저·관련 회귀 검사는 로컬에서 실행했다. 머지·운영 배포와 실제 결제는 별도이며 이 기록으로 성공을 대신하지 않는다.
- 운영 PayPal capture/refund, 운영 DB 조회/쓰기, 실제 MOOD 충전, 고객 데이터 접근·발송은 하지 않았다.
- 야간 투어 $49/인, 프라이빗 기본 $250, 고정환율 1,350 및 정수 달러 반올림은 현재 가격 계약으로 검사했다. 금액이 실제로 결제됐거나 운영 배포가 확인됐다는 뜻은 아니다.
- AI 플래너 $9.90 기본가의 $10 반올림 여부는 답변 대기이며, 그 외 확정된 가격 수정은 진행한다.
- 별도 시간제 8시간 차량 대여의 기존 330,000원은 1,350 환율로 $244다. 서울 프라이빗 투어와 같은 $250로 통일할지는 별도 확인 중이며, 응답 전에는 해당 요금표를 유지한다.
- K-pop 1인 요금과 별도 차량 요금표, 다도시 3일 상품의 상담 연결, 실제 거리 API 및 운영 설정·관리자 저장 상품의 가격은 이번 합성 검사를 운영 검증으로 확대하지 않는다.
