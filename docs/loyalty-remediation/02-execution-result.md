| 확인 대상 | 결과 | 확인 방법 |

| 서버 결제 경로 차단 | ✅ 차단됨 | `isRevoked === true` 를 보는 5경로(applyPromoCode · capturePaypalOrder · paymentGate · coupon-charge · refund-ledger) 기준으로 운영 문서 판정 |

## 이 실행이 지킨 것

- `pointHistory` 물리 삭제 0건 — correction 역분개만 추가
