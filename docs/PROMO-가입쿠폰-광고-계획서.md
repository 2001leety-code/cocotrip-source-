## 3. 추가/변경할 것 (홈페이지 업데이트 사항)

### 3-1. AI 플랜 무료 쿠폰 신설 ⭐ (핵심 — 새 경로)
⚠️ **발견(2026-06-27)**: AI 플랜은 현재 **"쿠폰 미적용, 모든 사용자 동일가($9.90)" 정책**(`PurchaseSection.tsx:87`). 쿠폰 적용은 **차터/투어만**(가입 5% 쿠폰, FEATURE_DISCOUNT_V2). → AI 무료 쿠폰 = **AI 결제에 쿠폰 적용 경로를 새로 만들어야 함**(현재 없음). 기존 쿠폰 *발급* 방식(onboarding-coupons)은 그대로, *AI 적용*만 신설.
- `onboarding-coupons.js`: AI 무료 쿠폰 추가 — `productScope:'ai-plan'`, `type:'free'`, `maxDays:3`(1~3일 한정).
- `paymentGate.js`: 'ai-coupon' provider 추가 — 쿠폰 검증(소유·미사용·1~3일 일정) → **0원 통과**(PayPal 우회, TEST-/ADMIN-BYPASS- 패턴 참고). 멱등성·중복사용 차단(쿠폰 isUsed 마킹 + used 가드).
- `PurchaseSection`: AI 무료 쿠폰 보유 시 "무료 쿠폰 사용" UI + 0원 결제 흐름(현 "쿠폰 미적용" 분기 예외).
- 4일+ 일정에 쓰면 거부(또는 차액 결제 — 추후).

### 3-1b. ③ 플랜 생성 크레딧 (새 메커니즘)
⚠️ 현재 = **1결제 = 1플랜**(`plan_issued_orders` 멱등) + `revisionCredits`(같은 플랜 **수정** 횟수, 새 플랜 아님). ③ "1결제 = 플랜 3개 생성"은 기존에 없는 개념.
- 결제 성공 시 사용자/주문에 `planCredits:3` 부여 → 플랜 생성마다 차감(0 되면 추가 생성 차단). 기존 revisionCredits 트랜잭션 패턴 재사용(동시성 안전).
- ②무료쿠폰(1개)과 ③크레딧(3개) **중첩 주의** — UX/카피로 구분.

### 3-2. "최대 10%" 할인 (대상 확정 후)
- §6 답에 따라: AI 플랜이면 새 할인, 차터면 기존 재사용.

### 3-3. "1+2" 구현 (§6 확정 후)
- 해석에 따라 쿠폰 추가발급 or 일수 보너스 or 타상품 쿠폰.

### 3-4. 광고 배너/랜딩 (프론트 + 4언어)
- `PromoBanner`/`PromoPopup` 카피 = "최대 10% + 3일 무료 + 1+2" (ko/en/ja/zh 동시 — CLAUDE.md 규칙).
- 광고 클릭 → 가입 유도 랜딩(또는 /planner). 전환 추적(GA4/PostHog 기존 패턴).
- 어드민 `PromoBannerPanel`에서 켜고 끄기.

### 3-5. 로그인 진입 + 가입 정보 수집 (운영자 2026-06-27 추가)
**현황**: 로그인 시스템 풍부(Google/Apple/LINE/전화/익명, `firebase.js`). 가입 시 `displayName`만 저장 + onboarding-coupons 호출. **추가 정보 수집 폼 없음.**

- **A. 로그인 진입**: 차터/AI/투어 CTA 버튼 → **바로 로그인/가입 모달**(가입 유도). 현 "결제→결과" 흐름에 로그인 진입점 추가. ⚠️ 게스트결제(이전 활성화)와 공존할지 결정.
- **B. 가입 정보 수집 폼** (구글 등 로그인 직후 "프로필 완성" 1회):
  - 닉네임 · **국가번호+전화번호(필수)** · 메신저 종류(WhatsApp/LINE/카카오/WeChat 등)+아이디 · (등등 — 항목 확정 필요)
  - `users/{uid}` 저장: `nickname`, `countryCode`, `phone`, `messengerType`, `messengerId`.
  - ⚠️ **PII = 개인정보 수집 동의 체크 + 처리방침**(외국인 = GDPR 등) 필수. 안 하면 법적 위험.
  - ⚠️ **가입 마찰**: 정보 많을수록 이탈↑ → 필수(닉네임/전화/메신저1개) vs 선택 구분 권장. 다 필수면 가입률 떨어짐.
- 가입 완료 → 무료 쿠폰(②) 발급 + 안내(`AIIntroModal`). 마이페이지 쿠폰함 + "사용하기"→/planner.

> ⚠️ 이 A/B는 프로모션(쿠폰)과 **별도 Phase**(로그인 UX + PII 폼) — 돈 코어 아니지만 PII/법무라 신중. P1(쿠폰)과 분리 진행 가능.

## 7. ⚠️ 주의 — 돈/혼동 리스크
